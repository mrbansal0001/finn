# FINN: every feature, and where it is

Written 13 Nov 2026 from the code as deployed (commit `ae88668`, https://finn-red.vercel.app). Each screen is listed **top to bottom, in the order things appear on a phone**, so an item's position in the list is where you'll find it. "Tap" means it opens or does something; everything else is information.

## 3. Filing card (`/card/{id}`)

Opened from any edition row, alert, filing list or search. Top to bottom:

| # | Feature | Where | What it does |
|---|---|---|---|
| 3.1 | ‹ Edition | Top | |
| 3.2 | Meta line | Top | Kind (Results, Management change, Price move…), ticker chip, "Lead" mark, time |
| 3.3 | Headline and company | | Serif headline written from the computed figures; the company name under it |
| 3.4 | Why it matters | Paragraph | Rule-written; for moves, only what the chart doesn't already say. Unread filings say "Not read yet: FINN reads it at its next update" |
| 3.5 | **Results chart** (results cards) | Under the why | Segmented **Growth / Margins** and **Compared with: a year ago / last quarter**. Growth: two bars per metric on its own zero-based scale (Revenue, EBITDA, PBT, PAT; banks NII, operating profit, provisions, PAT); a loss is outlined. Tap a metric for its filed figures. Margins: EBITDA margin a year ago, last quarter, now, as dots on a zero-based axis |
| 3.6 | **Price and volume chart** (move cards) | Under the why | 30 sessions: close line and volume bars with each day's 20-session average dashed; filing markers (hollow if filed after the close); breaks where the exchange's previous close differs. Readout of the selected session with "The alert" tag. Tap, drag or arrow keys to move along; a table of every value below. "Filed before this session: results, Tue 10 Nov 17:08" or that no filing came before it |
| 3.7 | **The question it raises** | Tinted call-out | A rule-written question from the figures, with **Investigate ›** (opens §4) |
| 3.8 | **From the filing** (people cards) | Section | Each person named: role, appointed/resigned, effective date; employers with years; schools. Then the verified-overlap sentence: who in your network overlapped (dated), or "No verified overlap with X: none of your 29 contacts' employers, schools and dates match", or that the network didn't load |
| 3.9 | **Who can explain this** | Section | People from your network: name (opens the person), how they're linked ("worked there 2015–19 while X was there"), Insider tag, "Reach them through Imran (they worked together at…)", "Last spoke Sep 2026". The first carries a **best placed** reason. Insider key line |
| 3.10 | **Exact figures** (results) | Fold on phones, open on wide screens | Results table: label, value, YoY, QoQ; margins in bp; banks add gross NPA; source link ("Results PDF, page 3 ↗"); "checked" line that opens the list of checks that ran |
| 3.11 | About this item | Foot fold | **Sources** (every source as a chip, saying when a link is a ZIP or raw XML), **Why this is here** (plain reasons: tier, % of portfolio, age), **How the order is computed** (tier, event type, weight × 4, age penalty, NSE category), Copy link |

## 4. Investigate (`/investigate`)

Opened from any **Investigate ›**: a card, a promise row, a results question. One page that carries the question through the evidence, the people and a follow-up.

| # | Feature | Where | What it does |
|---|---|---|---|
| 4.1 | Kicker "Investigate", company | Top | |
| 4.2 | **Editable question** | Top, serif | Starts as FINN's rule-written question ("Written by FINN from the figures below, by fixed rules. A question, not a finding."); tap to rewrite it in your words. Your wording is kept |
| 4.3 | Section jump links | Under the question | What changed, Evidence, People, Follow |
| 4.4 | **1. What changed** | Step | The figures (results chart, move chart, or a promise's replay), and **Still unclear:** what the figures can't tell you |
| 4.5 | **2. What to check next** | Step (side pane on wide screens) | The company's own words: promise rows or quotes, each with a label and page link ↗; long quotes fold to an excerpt with **Full quote** |
| 4.6 | **3. Who could help** | Step | **Lenses**: "What are you trying to understand?" Execution / Demand / Money / Rules, only those someone fits. People matched, each with **How you reach them** (a vertical path: You → introducer → them → company, every link saying its evidence), "Why them for this", Insider caution. **Draft an introduction request / Draft a note** (folded): an editable message with **Copy note** ("nothing is sent from FINN") |
| 4.7 | **4. Keep following** | Step | "Bring this question back": **Results / Call / Any filing / A date** (date picker); "What would resolve it (your test)" free text; **Follow this question** (then "Following", "Save changes"). Saved in this browser only, and it says so |
| 4.8 | About this page | Foot fold | Sources and method; Copy link |

## 13. Behind the scenes (not on screen, but what makes it work)

| # | What | Cadence |
|---|---|---|
| 13.1 | Reads NSE announcements and XBRL, classifies, ranks, writes cards | Every 15 minutes on the Mac worker |
| 13.2 | Results tables read from the PDF, checked against the statement's identities and exchange XBRL; withheld if checks fail | On filing |
| 13.3 | Price/volume from NSE's daily bhavcopy; every session over 1% / 1.2× kept so any rule works | After the close |
| 13.4 | Promises ledger built from four transcripts, every quote checked against its page | Nifty 50 pre-built; any company on request |
| 13.5 | Ask passages: transcripts and MD&A split by speaker, uploaded to a full-text index | When a ledger changes (5 per cycle) |
| 13.6 | Five-year trajectory from the annual report's own table | Once per report |
| 13.7 | Network matching: filing names and dates against your contacts, in your private rows only; no contact data goes to a model | Each export |
| 13.8 | Notifications sent per subscriber | Each cycle |
| 13.9 | Coverage requests from visitors queued and built | Each cycle (5 per visitor, 50 a day) |
| 13.10 | Supabase keep-alive | Daily (Vercel cron) |
| 13.11 | Anonymous demo sessions and their data deleted | After 14 days |
