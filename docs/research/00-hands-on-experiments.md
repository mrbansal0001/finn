# Hands-on experiments (10 Nov 2026)

E1 Transcript: INFY Q2 FY27 transcript (BSE PDF via screener) — 48 pages, 103,914 chars (~26K tokens), clean text layer. Explicit guidance: "revenue growth guidance is 1% to 2% YoY", "operating margin guidance remains at 20% to 22% for the year". Guidance revised quarterly → band-over-time viz. Pitfall: IT guidance in constant currency vs INR reported numbers.

Miss example: "Initiation of Forensic Audit" (Spandana Sphoorty) — material, non-standard label.

E15 Taxonomy and format variants: the NONINDAS XBRL (Dar Credit, SME) uses different tag names (`DepreciationAndAmortisationExpense`, `ExceptionalItems`, `ProfitLossForThePeriodFromContinuingOperations`). SME companies report half-yearly (`TypeOfReportingPeriod`), so there is no QoQ. Bank results (SBIN, 3 Nov PDF p.2): Interest earned, Interest expended, Operating profit before provisions, Provisions, GNPA/NNPA % (1.39%/0.36%), standalone and consolidated side by side (12 columns, ₹ crore). No bank results XBRL was reachable without the www API (the feed keeps only the last ~20 filings). → Tag-alias map per variant. Bank card = NII (computed), PPOP, Provisions, PAT, GNPA/NNPA in bp. "Half-yearly reporter" state.

E16 Bios for network matching (CIM XBRL: Huhtamaki and Repco; PDFs: SUNDARMFIN, VOLTAS, KIRLOSIND): the bio is free text, often giving employers and schools **without years** (SUNDARMFIN: IIT Madras, Stanford, Michigan, McKinsey NY, Microsoft, all undated), or relative durations only ("Amcor for 19 years" before Jan 2023). Some bios are "enclosed separately", in annexure pages. DIN is sometimes given (KIRLOSIND), which is an exact ID for directors. One CIM XBRL can list several people (Repco: 2 tenure completions). Re-appointments are frequent and low-signal. → An LLM structures the bio, with dates allowed to be unknown. Network claims are graded by evidence: "worked together" only when dates overlap; otherwise "both ex-McKinsey (dates not disclosed)". DIN match = certain. Re-appointments and tenure completions are ranked low.

E17 Promises ledger, hand-labelled gold set (BEL + DEEPAKNTR, 4 calls each, Q3FY26–Q2FY27; built by a subagent, quotes spot-checked independently 12/12): 84 guidance statements → 44 distinct promises. Per call: BEL 18/14/13/10, DEEPAKNTR 8/7/7/7. Statuses: delivered 8, partly 5, missed 4, revised 8, went silent 3, conflicting 1, too early 15. **Checkability: only 21% checkable against filed numbers; 44% only via management's own later statements (e.g. BEL order inflow, not in results filings); 33% not checkable.** Findings: PDF page = printed page + 1 (exchange cover letter); hyphenation at line breaks breaks naive quote matching; one call contradicted itself (BEL Q1FY27 closing remark 21–23% / >₹20,000 cr vs 28% / ₹55,000 cr earlier in the call); analyst-proposed numbers look like guidance; management says "on track" while dates slip (DEEPAKNTR polycarbonate date moved 3×; BEL QRSAM order slipped 3×); screener pages are standalone, which can't check consolidated or segment guidance. Transcripts are 11–17K tokens; a 4-call history is ≈60K. 3 of 4 BEL transcripts are scans with a usable OCR layer. Files: research/05-promises-ledger-gold/.

E18 Results page finding on 18 real Q2 FY27 results PDFs (portfolio, 11 Nov): text pages scored on statement labels (fuzzy, OCR-tolerant) and number density; 16/18 found as text. DEEPAKNTR and SHAILY results pages have no text layer at all (pure images) -> offered to the vision model as candidates. SBI's bank page needed bank labels and a looser "quarter … ended" pattern. -> pnl_candidates() returns ranked candidates; the transcription is accepted only if its arithmetic checks.

E19 Promise linking without a model (gold set as perfect extraction): metric-string matching recall 0.44 (BEL) / 0.39 (DN) -- management rewords promises call to call. Adding programme names/acronyms (QRSAM, NGC, MIBK) and FY compatibility: recall 0.78/0.83 but precision fell (QRSAM order vs QRSAM delivery merged). Adding promise facets (order, delivery, commissioning, utilisation, funding, margin, share, growth): P 0.88 / R 0.70 (BEL), P 0.75 / R 0.67 (DN). -> deterministic baseline kept; model-assisted linking for the semantic cases.
